# Tolou Concrete Driver 3D

بازی سه‌بعدی مرورگری «طلوع» برای شبیه‌سازی چرخه حمل بتن آماده؛ از کارخانه و بارگیری تا رانندگی، تحویل، تخلیه و بازگشت برای مأموریت بعدی.

## Game loop

`Order → Load → Drive → Park → Deliver → Return → Next Order`

هدف پروژه ساخت یک بازی آرکید/شبیه‌ساز سبک است، نه صرفاً نمایش یک کامیون سه‌بعدی. بازیکن باید تحت محدودیت زمان، کیفیت بتن، سلامت خودرو و دقت تحویل تصمیم بگیرد.

## Technology

- HTML5
- JavaScript
- WebGL
- Babylon.js
- GitHub Pages

Flash استفاده نمی‌شود. بازی در مرورگر اجرا می‌شود و در آینده در صورت نیاز می‌تواند به نسخه نصبی Desktop بسته‌بندی شود.

## Run locally

```bash
python -m http.server 8080
```

سپس:

```text
http://localhost:8080
```

## Controls

- `W / ArrowUp` گاز
- `S / ArrowDown` ترمز / دنده عقب
- `A / D` یا ArrowLeft / ArrowRight فرمان
- `Space` ترمز دستی
- `E` عملیات: بارگیری / تحویل / دریافت مأموریت بعدی
- `C` تغییر دوربین
- `R` ریست کامیون

## Product direction

نسخه هدف شامل این لایه‌هاست:

1. کارخانه و بچینگ
2. چند مقصد واقعی و متفاوت
3. مأموریت زمان‌دار
4. کیفیت/اسلامپ بتن به‌عنوان متغیر گیم‌پلی
5. سلامت خودرو و جریمه برخورد
6. پارک دقیق در محل تخلیه
7. امتیاز و رکورد
8. چرخه بازگشت به کارخانه
9. راننده/دیسپچر برای ایجاد فشار زمانی و شخصیت
10. توسعه بعدی به نقشه بزرگ‌تر، ترافیک، روز/شب، اقتصاد و progression
